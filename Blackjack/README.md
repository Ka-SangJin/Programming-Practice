# Blackjack Game

### 2025년 1학기

## 1. 프로젝트 개요

Python의 객체지향 프로그래밍 개념을 활용하여 블랙잭 카드 게임을 구현한 개인 과제 프로젝트입니다.

클래스와 상속을 이용해 카드, 플레이어, 딜러, 게임 진행 기능을 분리하여 설계했습니다.

## 2. 개발 환경

- **Language:** Python
- **Libraries:** random (Python 표준 라이브러리)

## 3. 주요 구현 기능

- 52장의 카드 덱 생성 및 무작위 셔플
- Hit / Stand 기능 구현
- A 카드의 점수를 1 또는 11로 자동 조정
- 딜러의 자동 카드 선택 (17점 이상에서 중단)
- Blackjack 및 Bust 판정
- 베팅 및 칩 관리
- 사용자 입력 예외 처리
- 게임 재시작 및 종료 기능

## 4. 객체지향 설계

| Class | Role |
|---|---|
| Card | 카드 정보 및 점수 관리 |
| Deck | 카드 덱 생성, 셔플 및 카드 분배 |
| Hand | 보유 카드와 총점 계산 |
| Player | 플레이어 행동 및 칩 관리 |
| Dealer | Player 상속 및 자동 플레이 |
| Game | 게임 진행 및 승패 판정 |

## 5. 실행 방법

```bash
python blackjack.py
```
